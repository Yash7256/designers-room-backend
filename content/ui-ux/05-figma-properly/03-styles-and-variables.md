# Styles & variables

*Name your colors, text and spacing once, then use the names. Change a value in one place and everything follows.*

## TL;DR

Name your colors, text and spacing once, then use the names. Change a value in one place and everything follows.

---

## Chapter 1: Change the wall color once

Imagine repainting a room where every brick has its own color. A nightmare. Now imagine one wall color. One decision, one change.

Styles and variables bring that to design. You save a value under a name, use the name everywhere, and update it in one place.

**In real life:** Your brand color changes from bright orange to a deeper orange. Without styles, you hunt through three hundred shapes. With styles, you change one value.

---

## Chapter 2: Styles

A style saves a set of properties under a name.

- **Color styles:** A saved fill or stroke color.
- **Text styles:** A saved font, size, weight and line height.
- **Effect styles:** Saved shadows or blurs.
- **Grid styles:** Saved layout grids from the Grids & spacing page.

Apply them by name. Edit the style once and every layer using it updates.

---

## Chapter 3: Variables

Variables store reusable values: colors, numbers, text, and true or false. They can also switch between sets of values called modes, which is how a design can flip between light and dark, or phone and desktop.

1. **Create a collection.** For example, "Colors".
2. **Add variables.** Like "background", "text" and "action".
3. **Add modes.** Like "Light" and "Dark".
4. **Assign values for each mode.**
5. **Apply variables to your fills, then switch the frame's mode and watch it change.**

Figma's features and plan limits change, so check Figma's help pages for what's available on your plan.

---

## Chapter 4: Name by purpose, not by value

A color called "Orange" is a problem the day it becomes blue. Name it for what it does.

- **By value (fragile):** "Orange", "Grey 3", "Big text"
- **By purpose (lasting):** "Action", "Text secondary", "Heading"

**In real life:** Calling a color "Orange" is like nicknaming your sibling "Tall". Fine, until they're not.

Start small: about five colors with clear jobs, five text styles, and the spacing values from your scale.

---

## Common mistakes

- Naming by value
- Creating hundreds of near-identical colors
- Applying colors by hand instead of using styles
- Skipping spacing values
